# Лабораторная работа № 5 — базовое SPA на React

**Герман Андреев, ИУ5-53Б**

**Тема «Прогноз нагрузки на сервер»**

LoadForecast показывает гостю паттерны нагрузки на сервер. В ЛР‑5 доступны лента, плитка с фильтрами и подробная карточка. Приложение написано на React и TypeScript, интерфейс собран на React-Bootstrap, маршруты работают через React Router.

## Запуск

Из корня репозитория. Понадобятся Node.js и npm.

```sh
cd frontend
npm ci
npm run dev
```

Открыть [http://localhost:5173](http://localhost:5173). Для проверки типов и сборки выполнить `npm run build` из каталога `frontend`.

## Страницы

| Страница | Что отображается | Действия |
| --- | --- | --- |
| **Лента** — `/load_patterns/feed` | Один паттерн с изображением, видео, названием, RPS, ожидаемым числом запросов и количеством лайков | «Следующий» выбирает ближайший больший ID. В конце списка лента возвращается к первому паттерну. «Подробнее» открывает карточку. |
| **Плитка** — `/load_patterns` | Карточки с изображением, названием, RPS и ожидаемым числом запросов. Фильтры по названию, ожидаемому числу запросов и диапазону RPS | «Найти» применяет введённые значения. «Сбросить» очищает фильтры. «Подробнее» открывает выбранную карточку. |
| **Карточка** — `/load_patterns/:id` | Изображение, видео, название, описание, код паттерна, сценарий применения, RPS, пиковый коэффициент, длительность, ожидаемое число запросов, дата создания | «К плитке» возвращает к списку. При неверном ID выводится «Паттерн не найден». |

В нижнем меню доступны «Лента» и «Плитка». «Добавление» и «Вход» отключены в гостевом интерфейсе ЛР‑5.

## Данные, фильтры и медиа

Все карточки загружаются из [mockPatterns](frontend/src/mocks/patterns.ts). При открытии страниц во вкладке **Network** видны загрузки приложения и медиафайлов. Запросов к REST API в ЛР‑5 нет.

Компонент [PatternFilter](frontend/src/components/PatternFilter.tsx) получает значения и обработчики через props. Страница плитки хранит введённые и применённые значения отдельно. [filterPatterns](frontend/src/utils/filterPatterns.ts) фильтрует список по введённым границам и части названия без учёта регистра.

[PatternMedia](frontend/src/components/PatternMedia.tsx) подставляет локальные SVG и MP4, если в записи нет ссылки или файл не загрузился. Это можно увидеть в [карточке «Ночной штиль»](http://localhost:5173/load_patterns/2). Состояние страниц хранится в `useState`, локальные данные загружаются в `useEffect`, ID для карточки считывается из URL через `useParams`.
