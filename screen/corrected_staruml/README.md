# Диаграммы LoadForecast

В [проекте Andreev_LoadPatterns.mdj](Andreev_LoadPatterns.mdj) находятся три редактируемые схемы по образцам для темы «Прогноз нагрузки на сервер». Те же рисунки вставлены в ТЗ и РПЗ и в файл исправлений на листы А4 в книжной ориентации.

| Диаграмма | Изображение |
| --- | --- |
| ER | [Таблицы и связи](<01 ER диаграмма.png>) |
| Классы | [Фронтенд, веб-сервис, модели и таблицы](<02 Диаграмма классов.png>) |
| Последовательность | [Сценарий из восьми запросов](<03 Диаграмма последовательности.png>) |

В ER отметка `N` означает, что поле может принимать `NULL`. По кнопке «Далее» обязательно название паттерна. Описание, фото и видео необязательны. RPS, пиковый коэффициент и длительность указываются при публикации. Полный состав таблиц PostgreSQL приведён в РПЗ.

На диаграмме классов четыре проектные страницы идут в один ряд. В последовательности три линии жизни, а восемь запросов связаны с операциями классов через свойство `signature`. Маршруты и cookie `session_id` соответствуют FastAPI.

## Как открыть

Откройте `Andreev_LoadPatterns.mdj` через **File → Open**. Если в редакторе видна сетка, снимите **Show Grid** в **Edit → Preferences → Diagram Editor**.

Для вставки схем в открытый проект скопируйте весь [Create_Diagrams.js](Create_Diagrams.js), выполните его в **View → Script Console** и сохраните проект. Скрипт добавляет отдельную модель с тремя диаграммами.
