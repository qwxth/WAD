# LoadForecast — фронтенд (React + TypeScript + React-Bootstrap)

Базовое SPA для гостя: просмотр паттернов нагрузки (услуг). Данные берутся только из коллекции mock-объектов (`src/mocks/patterns.ts`), бэкенд не используется. Redux и Context не применяются.

## Запуск

    cd frontend
    npm install
    npm run dev      # http://localhost:5173
    npm run build    # проверка типов + сборка

## Нижняя навигационная панель

Закреплена снизу на всех страницах, 4 пункта:

| Пункт | Состояние | Переход |
|---|---|---|
| Лента | доступен | /load_patterns/feed |
| Добавление | заблокирован | — |
| Плитка | доступен | /load_patterns |
| Вход | заблокирован | — |

## Страницы

### Лента — /load_patterns/feed
- Одна карточка паттерна: изображение, видео, название, RPS, ожидаемое число запросов, число лайков.
- Кнопка «Следующий» — переход к следующему паттерну (первый id больше текущего; после последнего возврат к первому, ID могут идти с пропусками).
- Кнопка «Подробнее» — переход на страницу паттерна.

### Плитка — /load_patterns
- Форма фильтра. Поля: «Название» (текст), «Ожидаемых запросов не более» (ползунок), «RPS от» и «RPS до» (числа).
- Кнопка «Найти» применяет фильтр (значения применяются только по ней), кнопка «Сбросить» очищает фильтр.
- Сетка карточек: изображение, название, RPS, ожидаемое число запросов, кнопка «Подробнее».
- Если ничего не найдено — сообщение «Ничего не найдено».

### Паттерн — /load_patterns/:id
- Полная карточка: изображение, видео, описание, код, применение, RPS, пиковый коэффициент, длительность, ожидаемое число запросов, дата создания.
- Кнопка «К плитке». Если id не найден — сообщение «Паттерн не найден».

## Изображение и видео по умолчанию
Если `image_url` / `video_url` равны `null` или изображение не загрузилось, показываются файлы из проекта: `src/assets/default-pattern.jpg` и `src/assets/default-pattern.mp4` (компонент `PatternMedia`).

## Компоненты и props
| Компонент | Props |
|---|---|
| PatternMedia | imageUrl, videoUrl, title, showVideo, height |
| PatternCard | pattern |
| PatternFilter | values, onChange, onApply, onReset |

## Используемые хуки
| Хук | Где | Зачем |
|---|---|---|
| useState | Tiles, Feed, PatternPage | список, значения фильтра, текущий id |
| useEffect | Tiles, Feed, PatternPage | начальная загрузка данных из mock |
| useParams (react-router) | PatternPage | чтение :id из URL |

## Стек
React 18, TypeScript, Vite, React-Bootstrap 2 / Bootstrap 5, React Router 6.
